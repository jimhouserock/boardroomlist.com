# boardroomlist.com AI skill

A Claude Code / Claude AI skill for [BoardroomList](https://boardroomlist.com): browsing and filtering senior Fortune 500 job postings, and what a paid membership unlocks.

See `SKILL.md` for the full walkthrough.

## Using this skill

Copy `SKILL.md` into a project's `.claude/skills/boardroomlist/` (or `.agents/skills/boardroomlist/`) directory so Claude can answer questions about how to use BoardroomList.
